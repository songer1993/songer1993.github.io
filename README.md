# qisongwang.com

Personal academic website of Qisong Wang. Live at [qisongwang.com](https://qisongwang.com); [songer1993.github.io](https://songer1993.github.io) redirects there.

Hand-written static HTML and CSS with no build step, no framework, and no external dependencies. Served by GitHub Pages from the `main` branch root.

## Files

- `index.html` — the entire site (single page)
- `styles.css` — styling, light and dark schemes via `prefers-color-scheme`
- `photo.jpg`, `favicon.svg` — assets
- `QisongWang_CV.pdf` — CV download
- `CNAME` — custom domain for GitHub Pages

## Updating

Edit, commit, push to `main`. GitHub Pages rebuilds automatically within a minute or two.
